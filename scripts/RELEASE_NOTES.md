**ShardForge**: the worldbuilder for Ultima Online (ServUO) in one download: the server with the map editor
and Walk (the walk-and-decorate client) built in, plus the command-line tool.

### Get started
1. Download **ShardForge-…-win-x64.zip** (Windows) or **…-linux-x64.tar.gz** (Linux) below and unzip it.
2. Start **ShardForge.exe**. Your browser opens http://localhost:2595.
3. Create the admin account and pick your UO client folder (ShardForge finds it for you and only reads it).

Nothing to install: .NET is included. Your work is saved in the `data` folder next to the program.
See QUICKSTART.txt inside the download, and the README on GitHub.

### In this version
- Editor: paint and sculpt, Ask Claude, full-size maps up to 7168 x 4096, soft terrain edges everywhere.
- Settlements: organic towns, villages and walled cities with building plots; drag to size; settings
  (farmland, clearing, hilltop, waterfront, winter, oasis) and switchable decorations; Populate world.
- Walk: walk your map with real client art, a full statics builder, and building plots on the ground.
- Server: accounts and roles, shared projects with history, Build & walk, live co-building; first-run setup
  finds your client folder; Admin settings page.
